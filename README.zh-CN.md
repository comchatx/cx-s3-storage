# cx-s3-storage

这个插件把 cx 连接到你自己的 S3 兼容存储，例如 Amazon S3、Cloudflare R2、Backblaze B2 或 Wasabi。连接存储桶后，cx 可以列出、读取、写入、复制和删除其中的文件，并能分段上传大文件。cx 存入这个存储桶的文件都有公开地址，可以用在需要文件链接的地方，例如亚马逊 listing 的主图。

## 连接存储桶

打开插件的「设置」，填写端点、存储桶、区域、访问密钥 ID、秘密访问密钥和公开地址。各项的获取方式见服务商的指南。如果密钥只能访问一个存储桶，cx 也只能使用这个存储桶。你的密钥由 ComChatX 保存，不会交给 cx。

## 费用

ComChatX 不收费。服务商照常向你自己的账号收费。

## 依赖

它和 cx-sources 一起安装，cx 通过 cx-sources 连接每个数据源。
