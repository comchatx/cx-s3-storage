# S3

这个插件把 cx 连到你自己的 S3 兼容存储：Amazon S3、Cloudflare R2、Backblaze B2、Wasabi，或任何提供 S3 API 的服务商。连上存储桶后，cx 用它的方式和你电脑上的 S3 客户端一样：列出、读取、写入、复制和删除文件，并分段上传大文件。cx 存进你存储桶的文件会有一个公开地址，cx 可以把它交给按链接取文件的服务，例如作为亚马逊 Listing 的主图。

## 连接你的存储

打开插件的设置，填写服务商的端点、存储桶和它的区域、访问密钥和它的私钥，以及存储桶文件的公开地址。服务商的指南会说明每一项在哪里找到。只限一个存储桶的密钥会让 cx 只用这个存储桶。你的密钥保存在 ComChatX 平台上，不会交给 cx。

## 费用

ComChatX 不收费。存储和请求的费用由服务商向你自己的账户收取，和任何客户端一样。

## 依赖

它和 cx-sources 一起安装，cx 通过 cx-sources 连接每个数据源。
